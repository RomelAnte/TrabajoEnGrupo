# Trabajo en Grupo - Portafolio Web

Proyecto colaborativo que presenta un portafolio web con perfiles personales de estudiantes de Sistemas de Información.

## 📋 Descripción

Este es un sitio web diseñado como trabajo en grupo que muestra los perfiles personales de dos estudiantes:

- **Romel Ante** - Estudiante de Sistemas de Información, apasionado por programación y calistenia
- **Victor Chiguano** - Desarrollador de software

El proyecto incluye navegación interactiva entre perfiles y una interfaz moderna y responsiva.

## 🎨 Características

- ✅ Diseño responsivo adaptable a dispositivos móviles
- ✅ Navegación intuitiva entre perfiles
- ✅ Interfaz moderna con Bootstrap 5
- ✅ Estilos personalizados y profesionales
- ✅ Gradientes y animaciones CSS
- ✅ Paleta de colores coherente

## 📁 Estructura del Proyecto

```
TrabajoEnGrupo/
├── index.html          # Perfil de Romel Ante
├── Prueba1.html        # Perfil de Victor Chiguano
├── README.md           # Este archivo
└── style/
    └── style.css       # Estilos personalizados
```

## 🚀 Inicio Rápido

1. Clona el repositorio
2. Abre `index.html` en tu navegador web
3. Navega entre los perfiles usando el menú superior

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura del contenido
- **CSS3** - Estilos y diseño responsivo
- **Bootstrap 5** - Framework CSS
- **CDN** - Recursos externos
